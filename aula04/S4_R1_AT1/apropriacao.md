# S4_R1_Situacao_Aprendizagem - Atividade de apropriação

---

| Elemento | Função |
| :--- | :--- |
| **Header** | Representa o cabeçalho da página ou de uma seção. |
| **Nav** | Representa uma área de navegação. |
| **Article** | Representa um conteúdo independente. |
| **Aside** | Representa um conteúdo complementar. |
| **Footer** | Representa o rodapé da página. |
